Things I've built

Chrome extension · v2.1

Grandma's Guardian

An anti-scam browser extension for elderly and vulnerable users. It began as my master's thesis at SANS and is now published on the Chrome Web Store.

It works the way a firewall should: deny by default. A trusted helper maintains the lists, and the extension enforces them quietly.

  • Domain allowlisting, so unknown sites never load
  • Download filtering by file type, blocking the installers scammers rely on
  • Hides common scam phrases on the page
  • Lists load locally or from a URL, so family can manage them remotely
